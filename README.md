# 🏛️ SALA CONNECT (ศาลาประชาคมออนไลน์ เทศบาลตำบลแม่สาย)

ระบบรับฟังความคิดเห็น สภาพปัญหา และข้อเสนอโครงการจากประชาชนเพื่อจัดทำแผนพัฒนาชุมชน เทศบาลตำบลแม่สาย อำเภอแม่สาย จังหวัดเชียงราย

---

## 🎯 มาตรฐานและสถาปัตยกรรมระบบ (Municipal Standards)
- **พอร์ตประจำระบบ (Port):** `3405` (จดทะเบียนตาม `DEC-022`)
- **เส้นทางหลัก (Web Slug):** `/sala/`
- **ระบบความปลอดภัย (Security Standard):** `DEC-026` Unified Security Radar (IP Geolocation, Brute-Force Shield)
- **การส่งมอบงาน (Deployment Standard):** `DEC-020` Two-Step GitOps (Local PC -> GitHub -> Cloud)

---

## 📂 โครงสร้างเส้นทางระบบ (System Endpoints)
| เส้นทาง | คำอธิบาย | กลุ่มผู้ใช้งาน |
|---|---|---|
| `/sala` | หน้าหลักศาลาประชาคมออนไลน์ (ข่าวสาร, เสนอโครงการ, ติดตามสถานะ) | ประชาชนทั่วไป / เจ้าหน้าที่ |
| `/sala/manage` | ระบบบริหารจัดการข้อเสนอโครงการและแผนชุมชน | เจ้าหน้าที่เทศบาล (ต้องล็อกอิน) |
| `/sala/print` | ระบบพิมพ์รายงานเอกสารและแบบเสนอโครงการมาตรฐาน A4 | เจ้าหน้าที่เทศบาล |
| `/sala/back` | ศูนย์บัญชาการความปลอดภัยและจัดการไอดี Master Key | ผู้ดูแลระบบสูงสุด (Master Key) |
| `/sala/api/health` | ตรวจสอบสถานะการทำงานของบริการ (Health Check) | ระบบตรวจการทำงาน |

---

## 🚀 การเริ่มต้นใช้งานในเครื่อง (Local Start)
- ดับเบิลคลิกไฟล์ `Start_Control_Center.bat` เพื่อเปิดบริการพอร์ต 3405
- หรือใช้คำสั่ง:
  ```bash
  npm install
  node control_center.cjs
  ```

---

## 🛡️ ข้อมูลและสิทธิ์ (Data Privacy & Invariants)
- จัดเก็บเฉพาะ 9 ช่องข้อมูลตามระเบียบแผนชุมชนแท้จริง (ไม่มีช่องงบประมาณ)
- ปฏิบัติตาม พ.ร.บ. คุ้มครองข้อมูลส่วนบุคคล (PDPA)
- รหัสผ่านและ Master Key ได้รับการปกป้องตามมาตรฐาน `DEC-000` และ `DEC-026`
